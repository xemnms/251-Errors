* Tasks:

    1. Create Your Own Class
    Create one Java class that represents a real-world entity that is needed by your term project. (example: Student, Seller, Buyer, Admin, etc.).
    
    Your class must demonstrate good object-oriented structure.
    
    2. Define Attributes
    Your class must contain at least 3 attributes (fields).
    
    Examples:
    - name
    - age
    - price
    - brand
    - status
    
    At least one attribute should be declared as a static attribute.
    
    Example:
    static int totalObjects;
    
    3. Define Behaviors (Methods)
    Your class must have at least 2 behaviors (methods).
    
    Requirements:
    - One method must have no parameters.
    - One method must accept at least one parameter.
    
    Example:
    turnOn()
    setName(String name)
    
    4. Implement Constructors
    Your class must include multiple types of constructors:
    
    - Default constructor (no parameters)
    - Parameterized constructor (accepts values)
    
    Optional bonus:
    - Create an overloaded constructor with different parameters.
    
    5. Use Static Members
    Your class must include at least one static field or static method.
    
    Example uses:
    - counting total objects created
    - utility method related to the class
    
    6. Share Your Class
    Commit and push your class to the team GitHub repository so your teammates can use it.
    
    7. Create an Object from a Teammate’s Class
    Update the ObjectDetailsPrinter.java
    Choose a class created by one of your teammates.
    
    Rules:
    - You cannot use your own class.
    - A class can only be used once for this activity.
    
    8. Create Objects Using Different Constructors
    From the teammate’s class, create at least two objects using different constructors.
    
    Example:
    
    Object 1 → created using the default constructor  
    Object 2 → created using the parameterized constructor
    
    9. Access and Display Attributes
    Print out the attributes of the objects you created.
    
    10. Trigger Behaviors
    Call and demonstrate the behaviors (methods) of the object.
    
    Requirements:
    - Call the method without parameters
    - Call the method that accepts parameters
    
    11. Demonstrate Static Usage
    Access or print the static attribute or static method of the class.
    
    Example:
    ClassName.staticField
    ClassName.staticMethod()
    
    12. Submit Your Work
    Commit and push the following to your repository:
    
    - Your original class
    - The program that creates and uses the teammate’s class objects
    
    Ensure your program compiles and runs successfully.
