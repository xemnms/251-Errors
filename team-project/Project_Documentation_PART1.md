**ORGANIZED SIMPLE USE CASES**  
REGISTER:    
As a general user, I can enter my personal details (name, email, password), so that I can create a new account.    
As a general user, I cannot register using an email that already exists in the system, so that each account is unique.  
As a general user, I receive an error message when required fields are missing or invalid, so that I can fix them before submitting the form.  
As a general user, I must agree to the terms and conditions before completing registration, so that I understand my responsibilities and the platform’s rules.  
As a general user, I can receive a verification code via email or authenticator, so that only verified users can activate an account.  
As a general user, I can successfully register and receive a confirmation message, so that I know my account has been created and ready to use.  


LOGIN/SIGNUP:  
As a general user, I can enter my email and password, so that I can access my account  
As a general user, I can reset my password if I forget, so that I regain access to my account  
As a general user, I can enter incorrect login details, so that the system gives me an error message to let me try again.  
As a general user, I can receive a verification via authenticator during login process, so that my account stays secure.  

CONTACTS:  
As a general user, I can.send messages to sellers or buyers.  
As a general user, I can review my conversation history.  
As a general user, I can receive notifications alerting me of new or unread messages.  
As a general user, I can see read receipts where it indicates if the other user has read my message.  
As a general user, I can send images, videos, and attachments.  
As a general user, I can react to messages with emojis.  

PLACE ORDER:   
As a Buyer, I can select a product or service I want to purchase, so that I can begin the ordering process.  
As a Buyer, I can view the price, description, and seller details of the item or service, so that I can confirm it fits my needs before ordering.  
As a Buyer, I can choose the quantity or specific service options, so that I can customize my order based on what I need.  
As a Buyer, I can add my selected product or service to my cart, so that I can compile all items I want to order in one place.  
As a Buyer, I can choose a payment option, so that I can complete the order using the method most convenient for me.  
As a Buyer, I can receive an order confirmation, so that I know my request has been successfully placed.  
As a Buyer, I can track the status of my placed order, so that I am aware of its progress until completion.  

POSTING:  
As a Seller, I can create a new product or service listing, so that I can offer it for sale on the platform.  
As a Seller, I can add a title, description, price, category, stock quantity, and images for my product or service, so that buyers have all the information needed to make a purchase.    
As a Seller, I can select delivery or service options (like shipping method, estimated delivery time, or service duration), so that buyers know how they will receive the product or service.  
As a Seller, I can remove or deactivate a product or service listing, so that unavailable items do not appear to buyers.  
As a Seller, I can view all my posted products or services in a dashboard, so that I can manage multiple listings efficiently.  
As a Seller, I can set promotional offers for my products or services, so that I can attract more buyers.  
As a Seller, I can categorize my products or services using tags or categories, so that buyers can easily find them when searching.  
As a Seller, I can receive notifications when a buyer places an order for my product or service, so that I can process it promptly.  
As a Seller, I can see order details, including buyer information, selected options, and quantity, so that I can fulfill the order correctly.  
As a Seller, I can update the order status (e.g., pending, processing, shipped, completed), so that buyers know the progress of their purchase.  
As a Seller, I can manage my inventory by updating stock quantities, so that buyers only order items that are available.  
As a Seller, I can view analytics of my listings, like views, orders, and revenue, so that I can make informed decisions about pricing or promotions.  
As a Seller, I can respond to reviews or ratings from buyers, so that I can maintain a good reputation and address any concerns.
