# 🐾 Bulldog BlueMarket (BBM)

A unified marketplace for the NU Laguna (NUL) community—connecting **independent sellers** and **buyers** in one platform for **products and services**.

___

## 📌 Project Name
**Bulldog BlueMarket**


## 📌 Description
Bulldog BlueMarket is a general marketplace designed for NU Laguna Community. I allows independent sellers to list products or services while enabling buyers to browse, place orders, and communicate seamlessly. The platform supports essential marketplace functions such as user registration, login, identity verification, posting, messaging, and order placement. 

## 📌 Target Users
- **General Users** — Anyone accessing the platform who must register, verify their identity, choose an account type, and use basic system features like messaging, reporting, or following.
- **NUL Buyers** — Students, faculty, and staff purchasing products or services.
- **NUL Sellers** — Independent NU Laguna sellers posting and managing their products or services.
- **Admin** — Authorized personnel who approve posts, moderate accounts, handle reports, and maintain marketplace integrity.
